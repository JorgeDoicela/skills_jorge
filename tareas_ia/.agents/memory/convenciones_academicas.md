# Convenciones Académicas y Estándares de Entrega

## 1. Normas APA 7 (Canal 1: `apa_docx.py`)
- **Estilo Visual:** Monocromático sobrio (texto negro, títulos negros, sin colores estridentes).
- **Tipografía:** Times New Roman o Arial 12pt con interlineado doble o 1.5 según especificación.
- **Estructura de Títulos:**
  - Nivel 1: Centrado, Negrita (usar para Referencias / Apéndices).
  - Nivel 2: Alineado a la izquierda, Negrita (usar para secciones principales: Introducción, Desarrollo, Conclusiones).
  - Nivel 3: Alineado a la izquierda, Negrita, Cursiva (usar para subsecciones).
- **Tablas y Figuras:**
  - Deben numerarse secuencialmente (Tabla 1, Figura 1).
  - Título breve y descriptivo en cursiva.
  - Nota al pie explicativa obligatoria.
  - **Regla python-docx:** Nunca colocar dos tablas seguidas sin un párrafo de texto intermedio.
- **Citas y Referencias:**
  - Toda afirmación técnica o teórica debe estar respaldada por una cita en el texto `(Autor, Año)`.
  - La sección Referencias debe incluir sangría francesa y orden alfabético estricto.

## 2. Tipografía Científica (Canal 2: `Typst`)
- **Márgenes:** 2.5 cm en los cuatro costados.
- **Fuentes:** Fuentes tipográficas legibles con soporte matemático completo (`Linux Libertine` o `New Computer Modern` para texto; `JetBrains Mono` para código).
- **Bloques de Código:**
  - Fondo gris tenue con bordes redondeados sutiles.
  - Números de línea activos para fragmentos de más de 5 líneas.
  - Sintaxis resaltada adecuada para cada lenguaje (`c`, `python`, `bash`).
- **Demostraciones y Teoremas:**
  - Uso de bloques destacados con barra lateral para teoremas, algoritmos y definiciones clave.
