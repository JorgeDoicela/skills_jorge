# Asignaturas del Primer Período Académico (UBE)

### 1. Comunicación y Comprensión Lectora
- **Foco:** Ensayos argumentativos, síntesis de textos, comprensión crítica y redacción formal.
- **Formato Predilecto:** Canal 1 (`apa_docx.py` -> DOCX/PDF) con normas APA 7 estrictas.
- **Puntos Clave:** Estructura clásica (Introducción, Tesis, Argumentos, Conclusión, Referencias). Cero faltas ortográficas.

### 2. Representación del Conocimiento y Razonamiento
- **Foco:** Lógica proposicional y de predicados, árboles de decisión, ontologías, grafos de inferencia y reglas para IA.
- **Formato Predilecto:** Canal 2 (`Typst` -> PDF) para tablas de verdad, reglas simbólicas y diagramas.
- **Herramientas:** Python (lógica simbólica), Typst, Graphviz/Mermaid.

### 3. Análisis y Resolución de Problemas
- **Foco:** Metodologías algorítmicas, diagramas de flujo, pseudocódigo, análisis de complejidad temporal y espacial (Big-O).
- **Formato Predilecto:** Canal 2 (`Typst` -> PDF) para algoritmos tabulados y notación matemática.
- **Puntos Clave:** Explicación paso a paso de cada invariante y caso borde.

### 4. Fundamentos de Redes
- **Foco:** Modelo OSI y TCP/IP, direccionamiento IPv4/IPv6, subredes (VLSM/CIDR), análisis de paquetes y servicios de red.
- **Formato Predilecto:** Canal 2 (`Typst` -> PDF) o Canal 1 si el docente exige plantilla Word.
- **Herramientas:** Wireshark, TShark, Nmap, Dnsutils, capturas de tráfico reales.

### 5. Sistemas Operativos
- **Foco:** Procesos, hilos (POSIX pthreads), syscalls de kernel (fork, exec, wait, pipe), sincronización (mutex/semáforos), gestión de memoria y CPU.
- **Formato Predilecto:** Canal 2 (`Typst` -> PDF) para presentar código en C y salidas de consola.
- **Herramientas:** GCC/Clang, GDB, Valgrind, Strace.

### 6. Programación Estructurada
- **Foco:** Programación en C/C++, punteros, aritmética de memoria dinámica (malloc/free), structs, matrices y recursión.
- **Formato Predilecto:** Canal 2 (`Typst` -> PDF) con bloques de código comentados y auditoría de memoria con Valgrind.
